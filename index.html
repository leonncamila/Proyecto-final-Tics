SOBRE GUARDIÁN IRTRA

Detectar. Alertar. Proteger.

El proyecto utiliza sensores y componentes electrónicos para supervisar zonas restringidas de mantenimiento. Cuando se detecta movimiento, el sistema genera señales de alerta para advertir una posible entrada no autorizada.

01

Detección

Un sensor PIR identifica movimiento dentro del área supervisada.

02

Procesamiento

Arduino recibe la señal del sensor y determina el estado del sistema.

03

Alerta

El sistema activa señales visuales y sonoras cuando detecta movimiento.
